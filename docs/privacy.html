Privacy Policy

Last updated: August 31, 2026

The short version

We collect nothing. huje.tools is a static website that documents open-source Python packages. There are no accounts, no cookies, no analytics, and no server that could receive your data.

The website

  • No analytics. No Google Analytics, no Plausible, no tracking pixels.
  • No cookies of any kind.
  • No accounts and no sign-up.
  • Served as static files by GitHub Pages, which keeps its own server logs. See GitHub's privacy statement.

The packages

Every package runs on your own hardware. They make no telemetry calls and report nothing back to us. What a package reads, writes, or sends is determined entirely by the code you write and the configuration you give it.

Some packages talk to services you choose, such as Nostr relays or a Lightning wallet you configure. Those are your relationships, governed by those services' own policies, and we are not party to them.

Installing

Packages are installed through PyPI, which has its own privacy notice. See PyPI's privacy notice.

Children

This site is not directed at children under 13 and we knowingly collect no information from anyone.

Changes

If this policy changes, the date above changes with it. The change history is public in the site's repository.
